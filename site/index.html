Services

What we do

We support automotive companies where technical uncertainty has to be turned into clear requirements, processes and measurable results.

01

Systems engineering

  • We define system architecture and functional decomposition for complex engineering projects.
  • We manage system requirements with full traceability.
  • We align architecture, implementation and verification across the V-model with cross-functional teams.
  • We identify product variants and set up variant management.

02

Embedded software

  • We develop embedded software in C and C++ for automotive control units, including AUTOSAR components.
  • We implement and optimise vehicle communication (CAN, FlexRay) and bootloader functions.
  • We integrate, test and debug ECU software in the vehicle system.

03

Verification and validation

  • We develop test cases, test environments, simulations and tools.
  • We build restbus simulations and configure test benches and HIL environments.
  • We analyse test results and feed findings back into development.

04

Process and compliance

  • We apply Automotive SPICE processes to system development and lifecycle management.
  • We write process descriptions and work instructions, e.g. for system architectural design (SYS.3).
  • We prepare audit-ready documentation for assessments and customer audits.

05

Functional safety and cybersecurity

  • We develop safety-critical requirements and architecture according to ISO 26262, up to ASIL D.
  • We define requirements for diagnostics and flashing according to ISO/SAE 21434, including firmware-over-the-air (FOTA) concepts.
  • We run risk analyses and security assessments.

06

Project and team coordination

  • We synchronise the work of interdisciplinary teams and keep communication flowing between them.
  • We track project status, risks and milestones, and report regularly to stakeholders.
  • We manage technical problems from root-cause analysis to verified resolution.

07

Prototype fleet management

  • We register and insure test and prototype vehicles in Poland, including pre-homologation vehicles.
  • We install and look after the measurement equipment the test programme needs.
  • We run test drives in Poland and across Europe, and analyse the results.
